# Bruno Martins - Currículo

Este projeto é um site de apresentação de currículo desenvolvido com HTML, CSS e JavaScript puro.

## Como usar

1. Clone ou baixe este repositório.
2. Certifique-se de que a imagem do perfil está em `assests/bruno.jpg`.
3. Abra o arquivo `index.html` no seu navegador.

## Estrutura
- `index.html`: Página principal do currículo
- `styles.css`: Estilos modernos e responsivos
- `script.js`: Navegação suave e destaque de seção
- `assests/bruno.jpg`: Foto de perfil

## Preview
Abra o arquivo `index.html` para visualizar o currículo interativo.
